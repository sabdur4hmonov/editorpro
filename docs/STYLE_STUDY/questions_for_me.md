# Faqat foydalanuvchi hal qiladiganlar

1. Beshta motion sinovida qaysi yo‘nalish doktor videolariga yoqadi? Harakat va ovoz didi kutilmoqda.
2. Haqiqiy SFX uchun original manba/litsenziya havolalarini bering; hozir tizim synth fallback ishlatadi. Yangi dastur kerak emas.
3. s21 (0–5s), s27 (7–18s), s31 (14–18s), s37 (33–48s) ni o‘zingiz tinglang: o‘tish zarbasi, nutq/musiqa muvozanati va soundning zichligi. Agent faqat aralash signal darajasini o‘lchadi, tembr yoki musiqiy beatni tasdiqlamadi.
4. True3D/fold va original qo‘lyozma stroke to‘liq kerak bo‘lsa, keyingi alohida ishda Blender/AE alfa eksportini ko‘rib chiqamiz; ushbu ishda install/download yo‘q.
